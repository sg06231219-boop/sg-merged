### 4. Helper Functions

## Key Design Decisions
- Pure vanilla JS (no CDN/framework dependencies)
- CSS variables for theming (client-side switchable)
- Hash-based SPA routing
- localStorage for cart persistence + address auto-fill
- Jinja2 template variables for server-side rendering
- Mobile-first responsive design with bottom nav
- 44px minimum touch targets
- Safe area insets for notch devices
- All Chinese UI text
